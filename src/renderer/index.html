CAMX STUDIO GUIDE

How to use CamX Studio

From phone connection to a verified final master.

THE SIMPLE WORKFLOWConnect. Preview. Choose. Render. Verify.Your original is never overwritten.
  1. 01
    Connect or add media

    Unlock the Android phone, select File transfer / Android Auto, then wait for automatic CamX scanning. You can also drag a supported clip into the window or choose Browse.

  2. 02
    Select a CamX clip

    Conversion videos are verified Cinema Cam masters and can be rendered. Saved videos can be downloaded and previewed, but are intentionally locked against another conversion.

  3. 03
    Review before conversion

    The selected clip opens in Preview automatically. Play the complete source and inspect framing, motion, audio and duration.

  4. 04
    Open Render

    Choose Render in the title bar or right-click the source and choose Render this video.

  5. 05
    Complete the three render steps

    Choose Output, then Processing, then Render. Maximum quality, Offline MFSR, Camera AI and Maximum GPU are the defaults when supported.

  6. 06
    Start and monitor

    Choose the save location and start the render. Activity shows the current stage, processed frames, FPS, elapsed time and remaining time.

  7. 07
    Use the verified result

    The output is fully decoded and checked before publication. Keep the JSON receipt and any LUT or quality-evidence companion beside the master.

01

Prepare the phone

Record with the CamX cinema pipeline. Connect the unlocked phone by a data-capable USB cable and choose File transfer / Android Auto on Android. The Phone workspace refreshes automatically every five seconds. If it remains empty, reconnect the cable, keep the phone unlocked and choose Refresh.

Only CamX, NeoProCamX and CamXNPV10 pipeline locations and validated companions are accepted. Ordinary phone videos are intentionally excluded.

02

Import and inspect

Select Conversion videos or Saved videos, tick one or more clips and choose Download to library. Downloaded clips stay in the same Source videos list with an IN LIBRARY marker. Saved videos remain preview-only; only Cinema Cam masters enable Render.

03

Choose the output contract

SDRRec.709 SDR. An SDR source is restricted to this SDR-to-SDR route.
CAMX HDRRAW to proprietary NDR10+ at 5,000 nits or NIVUKX Vision at 10,000 nits using the locked camera delivery math.
NEOLOGRAW to scene-referred Base, Shadow, Highlight or Cinema with a verified viewing LUT.
RAWBit-exact RAW Preserve or identity-mosaic CinemaDNG. All image processing is bypassed.

Next choose 4:4:4 RGB pixel-lossless, uncompressed 4:2:2, or codec-lossless 4:2:0. Chroma subsampling is not reversible; CamX Studio states that scope explicitly and never changes the selection silently.

04

Choose processing

Maximum uses the full 8-frame Offline MFSR plan and most frequent bounded AI analysis. Production uses five frames. Fast uses three frames for review work. MFSR rejects uncertain motion and resets at scene cuts; Camera AI is limited by edge, highlight and temporal guards.

RAW identity outputs hide these controls because any enhancement would violate sensor identity.

05

Understand Maximum GPU

Automatic mode sends every parity-validated MFSR, NIV99, AI and NDR/NIVUKX stage to the fastest compatible GPU path. NVIDIA, AMD and Intel adapters are supported through WebGPU and DirectML. Lossless 4:2:0 uses NVENC only after an encode/decode SHA-256 equality test; otherwise exact FFV1 is selected.

FFV1/r210/v210 packing, RAW unpack/develop, global registration, file I/O and final validation can remain CPU-owned. GPU percentage depends on the hardware and selected transport; the Stage ownership panel reports the real plan without claiming a fixed percentage.

06

Render and verify

Choose a destination, review Selected render and start. Activity reports live FPS and ETA. The source is hashed before and after conversion, the output is fully decoded, and exact codec, chroma, precision, colour signaling, frame timing and audio are validated before the final file is published.

07

Fast troubleshooting

  • Phone not visible: unlock it, select file-transfer mode, use a data cable and choose Refresh.
  • Render is dim: select a supported source and wait for engine checks to show Ready.
  • GPU encode uses CPU: the chosen codec or chroma has no quality-safe hardware encoder; GPU image processing still runs when available.
  • Conversion fails: read the Activity error. Partial outputs are removed automatically and the original stays untouched.
08

Optional keyboard workflow

Open media: Ctrl+O   Render: Ctrl+R   Phone/Preview/Activity: Ctrl+1/2/3   Play: Space   Start render: Ctrl+Enter   Help: F1.
